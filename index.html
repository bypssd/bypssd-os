El proyecto

Una forma cercana
de volver a empezar.

BYPSSD OS es una distribución Linux independiente impulsada por BYPSSD Informática Retro. Nace con una idea sencilla: ofrecer un entorno agradable y práctico para el uso diario, con personalidad propia.

Un escritorio
a tu manera.

KDE Plasma pone el control en tus manos. Organiza tus ventanas, ajusta el entorno y encuentra una forma cómoda de trabajar, con el amarillo BYPSSD como punto de partida.

Ideas que
se convierten en algo.

LibreOffice para tus documentos y presentaciones, Okular para tus PDF y Chromium o Firefox para explorar la web. Herramientas conocidas para oficina y educación.

Más posibilidades.
Menos complicaciones.

Descubre aplicaciones con Discover y utiliza los repositorios oficiales de la base. El canal BYPSSD Updates está preparado para las futuras actualizaciones propias del proyecto.

Estamos construyendo el camino.

BYPSSD OS está en fase experimental. Puede contener errores y su compatibilidad depende del equipo. El arranque Live se ha probado en entornos virtuales; el hardware físico y Secure Boot requieren más validación. Pruébalo primero en modo Live y comparte lo que encuentres.
